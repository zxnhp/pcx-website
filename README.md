# 鹏诚祥电子科技企业官网

蓝色科技风官网，参考用户提供的托盘图片。公司：惠州市鹏诚祥电子科技有限公司；电话：13510713508。

## 本地启动

需要 Node.js 22 或更新版本，无第三方依赖，无需 npm install。

```bash
npm run dev
```

访问 http://localhost:5173 。独立 API 运行在 127.0.0.1:3001，开发服务器代理 `/api/` 请求。Ctrl+C 停止服务。

```bash
npm test
```

## 架构和功能

- `frontend/`：可独立部署的 HTML、CSS、JavaScript 与图片。正文直接包含在 HTML 中，不依赖 JavaScript 才能被搜索引擎读取。
- `backend/server.mjs`：独立 Node.js HTTP API，服务端校验、访问频率限制、管理员身份验证。
- `backend/data/inquiries.jsonl`：询价记录，每行一条 JSON。**包含个人信息，禁止放到公开目录或提交版本控制。**
- 业务搜索、手机导航、电话拨号、产品预选、在线询价、隐私说明。
- 没有伪造客户案例、企业资质或成立年限。业务描述须由公司上线前审核。
- 提交询价只保存到后端，不发送短信或微信提醒。目前使用受保护的查询接口读取，未实现可视化管理后台。

## 管理询价

正式使用时设置随机高强度管理员令牌（至少 32 字节），妥善保存，不可写入前端：

```bash
export ADMIN_TOKEN="$(openssl rand -hex 32)"
# 保存该令牌到安全的部署配置中，后续使用同一个值
npm run dev
```

另一个终端使用相同令牌：

```bash
curl -H "Authorization: Bearer $ADMIN_TOKEN" http://127.0.0.1:3001/api/inquiries
```

未设置 ADMIN_TOKEN 时禁止查询；表单提交仍可使用。正式网站查询应经 HTTPS 或 SSH 隧道进行，不要通过明文公网传输令牌。业务人员应定期查看询价。JSONL 适合小型单实例站点；更大流量应改为数据库、分页管理和共享限流。

## 正式部署：前后端分离

前端静态文件由 Nginx 托管，后端独立运行，Nginx 将 `/api/` 代理给后端。同一域名下代理接口，不需要开放跨域权限。

1. 准备域名、服务器和 HTTPS 证书。中国大陆服务器通常需要 ICP 备案，具体按服务商及主管部门要求办理；取得真实备案号后在页脚添加备案链接。
2. 将 `frontend/` 部署到 `/var/www/pcx/`，后端和数据存放到非公开目录。
3. 使用 systemd 或其他进程管理器运行 `node backend/server.mjs`，设置环境变量（Node 不自动加载 `.env`）：
   - `HOST=127.0.0.1`
   - `PORT=3001`
   - `ADMIN_TOKEN=安全随机令牌`
   - `DATA_DIR=/var/lib/pcx`（应用账户可读写，禁止其他用户访问）
   - `ALLOWED_ORIGIN=https://真实域名`
   - `TRUST_PROXY=1`（仅在后端不可直接公网访问且可信代理覆盖 X-Real-IP 时开启）
4. Nginx 配置参考 `deploy/nginx.conf.example`，替换域名、路径、证书。确保 HTTP 重定向至 HTTPS。
5. 定期备份数据；根据咨询处理情况执行保留/删除政策。记录无自动过期机制，运营方需定期清理已无需保留的询价。数据目录不要和公网静态文件放在一起。

## 百度、必应等搜索引擎收录

现有页面提供标题、描述、语义化正文、企业结构化数据和 robots.txt；无需 SPA 预渲染。拿到真实域名后，在部署前运行：

```bash
node scripts/seo.mjs https://真实域名
```

该命令生成 canonical、og:url、真实域名的 `sitemap.xml`，并更新 `robots.txt`。随后部署更新后的前端。

- 在百度搜索资源平台、Bing Webmaster Tools 等验证域名并提交站点地图。
- 检查首页、robots.txt 和 sitemap.xml 公网返回 HTTP 200，不要求登录，不被防火墙拦截。
- 根据真实业务持续补充型号、回收范围、常见问题等原创内容；避免堆砌关键词。
- 收录和排名由搜索引擎决定，不能承诺上线立即可搜索，也不能保证排名。
